# AI Atlas — Sprint 04 integration

This is an additive content sprint for the existing Docusaurus repository.

## Copy

Copy the contents of this package into the root of your local `AI-Atlas` repository. Do not nest the wrapper directory.

## Add the sidebar entries

If your `sidebars.ts` uses explicit item lists, add these document IDs under a suitable category:

```ts
'models/transformers',
'systems/model-lifecycle',
'systems/inference-and-serving',
'evaluation/evaluation-design',
'safety/trustworthy-ai',
'visual/ai-system-map',
```

Remove the leading space before each quoted ID when pasting. A cleaner category block is:

```ts
{
  type: 'category',
  label: 'AI systems',
  items: [
    'models/transformers',
    'systems/model-lifecycle',
    'systems/inference-and-serving',
    'evaluation/evaluation-design',
    'safety/trustworthy-ai',
    'visual/ai-system-map',
  ],
},
```

Add `updates/sprint-04` to the existing updates category if one exists. If your sidebar is autogenerated, no sidebar edit is required.

## Validate locally

```bash
npm install
npm run build
```

Then commit and push:

```bash
git add docs SPRINT-04-INTEGRATION.md
# Include sidebars.ts if you edited it
git commit -m "Add AI systems layer"
git push origin main
```
