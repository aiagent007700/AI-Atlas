# AI Atlas — visual and systems sprint 02

This sprint upgrades the public tutorial with:

- A more legible visual homepage that keeps the orbit motif but adds learning lanes and signal cards
- A visual grammar page for reading system diagrams
- A diagram-led RAG evaluation chapter
- A diagram-led agentic-skills chapter
- Sidebar navigation for the new modules
- Additional public research and industry sources in `config/sources.json`

## Apply

Copy the contents of this folder into the root of your existing `AI-Atlas` repository. Preserve `.github` and replace files when prompted. Then run:

```bash
npm install
git add .
git commit -m "Improve AI Atlas visuals and add RAG and skills modules"
git push origin main
```

The GitHub Pages workflow should rebuild the site automatically.

## Visual direction

The new homepage is designed as a learning dashboard: the orbit is retained as the identity mark, while the page now makes the three learning modes, frontier signals, and editorial question visible without requiring a click.
