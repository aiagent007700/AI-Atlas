# Deep dives integration

This package adds a learner-facing `docs/deep-dive/` section. It contains detailed chapters, labs, and a reference policy. It does not replace the existing sidebar.

Add this category to the top-level `items` array in `sidebars.ts`:

```ts
{
  type: 'category',
  label: 'Deep dives',
  items: [
    {
      type: 'autogenerated',
      dirName: 'deep-dive',
    },
  ],
},
```

The overview intentionally relies on autogenerated navigation instead of fragile relative links. This avoids route-resolution errors when the site uses nested document directories.

## Verification

Run:

```bash
python scripts/preflight_depth_expansion.py
npm install
npm run build
```

The preflight checks front matter, code fences, forbidden public release terminology, and obvious MDX-sensitive expressions. The full Docusaurus build remains the final authority because it validates the existing repository and sidebar together.
