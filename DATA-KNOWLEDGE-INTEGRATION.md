# Data and knowledge systems integration

This module is public-facing and intentionally has no internal organization references.

## Files

All tutorial pages live under `docs/data-knowledge/`.

## Sidebar

Add this category to the existing `items` array in `sidebars.ts`:

```ts
{
  type: 'category',
  label: 'Data and knowledge systems',
  items: [
    {
      type: 'autogenerated',
      dirName: 'data-knowledge',
    },
  ],
},
```

Do not add individual document IDs when using `autogenerated`.

## Validation

```bash
python scripts/preflight_data_knowledge.py
npm run build
```

The preflight checks front matter, fenced code blocks, public terminology, external URL syntax, and the expected module directory. It does not replace the Docusaurus build.
