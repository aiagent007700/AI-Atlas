# Learning systems integration

This package adds a public-facing **Learning systems** category under `docs/learning-systems/`.

Add this object inside the existing `items` array in `sidebars.ts`:

```ts
{
  type: 'category',
  label: 'Learning systems',
  items: [
    {
      type: 'autogenerated',
      dirName: 'learning-systems',
    },
  ],
},
```

Do not replace the existing sidebar. Insert the category once.

## Verification

```bash
python scripts/preflight_learning_systems.py
npm run build
```

The content intentionally avoids raw LaTeX, JSX expressions, fragile relative links, and unquoted front-matter values containing colons.
