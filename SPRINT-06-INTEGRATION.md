```ts
  label: 'Trust, security, and governance',
  items: [
    'safety/index',
    'safety/threat-modeling',
    'safety/prompt-injection',
    'safety/privacy-and-data',
    'safety/governance-and-standards',

```

Add the category before the Living updates category. If your sidebar already uses autogenerated docs, no sidebar change is required.
