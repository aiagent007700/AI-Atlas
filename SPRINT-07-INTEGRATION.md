# Sprint 7 integration guide

## Copy into the repository

Copy the contents of this package into the root of the existing `AI-Atlas` repository. The new tutorial pages live under:

```text
docs/agents/sprint-07/
```

The package does not change `package.json`, JSX, CSS or the existing site configuration.

## Add the sidebar category

Open the existing `sidebars.ts` and add this object inside the appropriate top-level `items` array. Do not replace the complete file.

```ts
{
  type: 'category',
  label: 'Agents, skills and protocols',
  items: [
    {
      type: 'autogenerated',
      dirName: 'agents/sprint-07',
    },
  ],
},
```

If your sidebar already has an `Agents` category, add the nested category there instead of creating a second top-level category.

## Validate before pushing

```bash
python scripts/preflight_sprint7.py
npm install
npm run build
```

Then commit only after the build succeeds:

```bash
git add docs/agents/sprint-07 scripts/preflight_sprint7.py SPRINT-07-INTEGRATION.md sidebars.ts
git commit -m "Add expanded agents skills and protocols tutorial"
git push origin main
```

## If the sidebar build reports an unknown document

The most common cause is a manually typed document ID that does not match the file path. The autogenerated category above avoids that problem. If you choose explicit IDs, use the IDs from each page front matter, which all begin with `sprint-07-`.
