# Sprint 8 integration

Sprint 8 is additive. Copy the `docs/` and `scripts/` directories into the repository root.

## Sidebar

Add this category inside the main `items` array in `sidebars.ts`:

```ts
{
  type: 'category',
  label: 'Multimodal and generative AI',
  items: [
    {
      type: 'autogenerated',
      dirName: 'multimodal/sprint-08',
    },
  ],
},
```

If an existing category already covers `multimodal`, place the autogenerated item inside that category instead of creating a duplicate section.

## Validation

Run from the repository root:

```bash
python scripts/preflight_sprint8.py
npm install
npm run build
```

The sprint does not change dependencies, configuration, or the homepage.
