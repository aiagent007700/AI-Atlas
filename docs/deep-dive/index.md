# Deep dives

The Deep dives collection is the tutorial's detailed layer. Each chapter moves from an intuitive model to implementation mechanics, operational trade-offs, failure modes, and a practical exercise.

The goal is not to make every page encyclopedic. The goal is to make each page useful when you need to explain a design, evaluate a system, or decide what to build next.

## How to use this section

* Read the **Foundations** chapter first if you are new to modern AI systems.
* Use **Knowledge systems** when your problem involves retrieval, grounding, or enterprise information.
* Use **Agents** when the system must choose actions, call tools, or manage state.
* Use **Serving** when a prototype needs to become a reliable production service.
* Use **Networks** when AI is part of operations, assurance, orchestration, or a telecom control loop.
* Use the **Labs** as short design exercises. They are intentionally model-agnostic and can be completed with diagrams and test data before any API is selected.

## The chapter contract

Every detailed chapter includes:

* Learning objectives and prerequisites
* A system model and mechanism-level explanation
* A worked example
* Trade-offs and failure modes
* Evaluation questions
* A practical exercise
* A reference shelf with primary, implementation, and research sources

## A recurring question

A useful AI tutorial should not only answer “How does this work?” It should also answer “What evidence would change my mind?” and “What would fail first in production?”

The references are external and public. They are curated as learning aids, not endorsements. Links marked **primary** point to standards, official specifications, original papers, or official project documentation. Links marked **implementation** point to maintained software projects. Links marked **research** point to papers or research collections.
