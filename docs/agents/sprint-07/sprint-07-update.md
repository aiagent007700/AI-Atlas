# Sprint 7 update: agents, skills and protocols

Sprint 7 expands the tutorial from short orientation pages into a deeper learning path for agentic systems. It adds architecture, implementation choices, reusable skill design, interoperability boundaries, multi-agent trade-offs, evaluation, observability, security and hands-on labs.

## What changed

- Added eight detailed chapters under the `agents/sprint-07` document directory.
- Added Mermaid diagrams for the autonomy spectrum, agent loop, skill anatomy, protocol boundaries, evaluation layers and risk-tiered actions.
- Added a reference shelf with official specifications, documentation, maintained repositories and practical guidance.
- Added labs that produce contracts, evaluation matrices and recovery plans.
- Added a sidebar integration snippet rather than replacing the existing project sidebar.
- Added a static preflight checker for Sprint 7 content.

## Editorial stance

The tutorial separates claims about a project from claims about the quality of an implementation. External references are evidence for definitions, interfaces or documented capabilities; they are not automatic proof of production readiness.
