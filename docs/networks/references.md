# Reference shelf: networks, telecom and IT

## How to use the shelf

Start with a primary or normative source for architecture and requirements. Pair it with an implementation or operations source to understand how the idea behaves in practice. Treat vendor claims and community examples as evidence about an implementation, not as proof of a general result.

## Primary and standards sources

- [3GPP specification portal](https://www.3gpp.org/DynaReport/) — mobile system specifications and reports.
- [3GPP TS 23.501](https://www.3gpp.org/DynaReport/23501.htm) — 5G system architecture.
- [3GPP TS 23.502](https://www.3gpp.org/DynaReport/23502.htm) — 5G system procedures.
- [ETSI ZSM](https://www.etsi.org/technical-groups/zsm/) — zero-touch network and service management.
- [ETSI ENI](https://www.etsi.org/technical-groups/eni/) — experiential networked intelligence.
- [TM Forum Autonomous Networks](https://www.tmforum.org/missions/autonomous-networks) — autonomy framing, maturity and operating context.
- [TM Forum Open APIs](https://www.tmforum.org/oda/open-apis/) — management and service API context.
- [O-RAN Alliance](https://www.o-ran.org/) — open and intelligent RAN ecosystem.
- [ITU-T machine learning for future networks](https://www.itu.int/en/ITU-T/focusgroups/ml5g/pages/default.aspx) — architectural study material.
- [IETF RFC Editor](https://www.rfc-editor.org/) — Internet protocols and data models.

## Platform and operations sources

- [Kubernetes documentation](https://kubernetes.io/docs/home/) — orchestration and lifecycle.
- [CNCF cloud native definition](https://github.com/cncf/toc/blob/main/DEFINITION.md) — common cloud-native vocabulary.
- [Google SRE book](https://sre.google/sre-book/table-of-contents/) — reliability engineering principles.
- [Google SRE workbook](https://sre.google/workbook/table-of-contents/) — practical reliability patterns.
- [OpenTelemetry documentation](https://opentelemetry.io/docs/) — telemetry instrumentation and collection.

## Evidence notes

For every reference used in a chapter, record the source type, title, publisher, version or date where available, scope and the claim it supports. A link is not a substitute for reading the relevant section.
