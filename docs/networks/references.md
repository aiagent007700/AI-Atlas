# Reference shelf: networks, telecom and IT

## How references are selected

The shelf favors primary specifications, standards bodies, official documentation and maintained project sources. A reference is not treated as proof merely because it is official. Each source should still be read for scope, status, assumptions and version.

### Primary and standards sources

* [3GPP specification portal](https://www.3gpp.org/DynaReport/): normative specifications and reports for mobile systems.
* [3GPP TS 23.501](https://www.3gpp.org/DynaReport/23501.htm): system architecture for the 5G System.
* [3GPP TS 23.502](https://www.3gpp.org/DynaReport/23502.htm): procedures for the 5G System.
* [ETSI ZSM](https://www.etsi.org/technical-groups/zsm/): zero-touch network and service management.
* [ETSI ENI](https://www.etsi.org/technical-groups/eni/): experiential networked intelligence.
* [TM Forum Autonomous Networks](https://www.tmforum.org/missions/autonomous-networks): autonomy levels, architecture and business framing.
* [TM Forum Autonomous Networks framework](https://www.tmforum.org/resources/introductory-guide/autonomous-networks-business-requirements-and-framework-v3-0-0-ig1218/): business requirements and framework material.
* [O-RAN Alliance](https://www.o-ran.org/): open and intelligent RAN ecosystem.
* [ITU-T ML5G](https://www.itu.int/en/ITU-T/focusgroups/ml5g/pages/default.aspx): machine learning architecture for future networks.
* [MEF LSO implementation](https://www.mplify.net/lso-sonata-implementation/): implementation-oriented material for lifecycle service orchestration.

### Platform and operations sources

* [Kubernetes documentation](https://kubernetes.io/docs/home/): orchestration, lifecycle and observability concepts.
* [CNCF Cloud Native Definition](https://github.com/cncf/toc/blob/main/DEFINITION.md): common cloud-native vocabulary.
* [Google SRE book](https://sre.google/sre-book/table-of-contents/): reliability engineering principles and practices.
* [IETF RFC 7950](https://www.rfc-editor.org/rfc/rfc7950): YANG 1.1 data modeling language.

### How to use this shelf

For an architecture question, start with 3GPP and the relevant management standards. For an operations question, pair the normative source with platform and SRE references. For an AI question, identify the decision, evidence, action and verification boundary before reading implementation material.

## Source-quality note

Vendor material and community projects can be valuable for implementation insight, but they should be labeled as an interpretation or implementation reference. They should not silently replace a normative specification or an independently measured result.
