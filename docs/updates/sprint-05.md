# Sprint 5 production AI engineering

This sprint adds the operational layer between an AI concept and a dependable service.

## Added modules

* Data and dataset quality
* Model adaptation
* LLMOps and release discipline
* AI observability
* Quality cost and latency
* Production AI system map

## Editorial theme

The frontier is not only better models. It is better systems around models: stronger data contracts, more honest evaluations, safer releases, useful traces, and explicit trade-offs.

## Build-safe design

This sprint intentionally uses plain Markdown, fenced diagrams, quoted-safe front matter, and external links. It does not add dependencies or modify the homepage.

## Suggested reading order

1. Read the production engineering overview.
2. Choose data or model adaptation.
3. Read LLMOps before observability.
4. Finish with quality, cost, and latency.
5. Use the system map to connect the pieces.
