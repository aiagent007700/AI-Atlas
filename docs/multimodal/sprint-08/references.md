# Reference shelf — multimodal and generative AI

This shelf is curated for learning and implementation. A reference is included because it is primary, official, maintained, or unusually useful—not because it is automatically correct for every deployment.

## Tier 1 — Foundational research

- [Vision Transformer](https://arxiv.org/abs/2010.11929) — patch-based visual representation with transformer architecture.
- [Denoising Diffusion Probabilistic Models](https://arxiv.org/abs/2006.11239) — foundational diffusion formulation.
- [High-Resolution Image Synthesis with Latent Diffusion Models](https://arxiv.org/abs/2112.10752) — diffusion in a learned latent space.
- [Whisper](https://arxiv.org/abs/2212.04356) — large-scale multilingual speech recognition.
- [World Models](https://worldmodels.github.io/) — compact introduction to learned environment models.
- [MuZero](https://arxiv.org/abs/1911.08265) — planning with a learned model without explicit environment rules.

## Tier 2 — Official projects and maintained implementations

- [OpenAI Whisper repository](https://github.com/openai/whisper) — speech recognition implementation and model release.
- [Hugging Face Diffusers](https://huggingface.co/docs/diffusers/index) — diffusion pipelines, schedulers, and training material.
- [Segment Anything repository](https://github.com/facebookresearch/segment-anything) — promptable image segmentation.
- [Hugging Face vision task guides](https://huggingface.co/docs/transformers/tasks/image_classification) — practical model and task workflows.
- [Habitat](https://aihabitat.org/) — embodied AI simulation and research platform.
- [Open X-Embodiment](https://robotics-transformer-x.github.io/) — cross-robot data and generalization reference.
- [DreamerV3](https://danijar.com/project/dreamerv3/) — learning behavior through latent world models.

## Tier 3 — Benchmarks and datasets

- [COCO](https://cocodataset.org/) — object detection, segmentation, and captioning benchmark.
- [Kinetics](https://deepmind.google/discover/blog/kinetics-dataset/) — large-scale human action video dataset.
- [LibriSpeech](https://www.openslr.org/12) — speech recognition benchmark.
- [MMMU](https://arxiv.org/abs/2311.16502) — multimodal reasoning benchmark.
- [MMBench](https://arxiv.org/abs/2307.06281) — multimodal large-language-model evaluation.
- [HEIM](https://arxiv.org/abs/2311.04287) — holistic evaluation of text-to-image models.

## How to use this shelf

Start with one primary paper, one implementation, and one benchmark. Reproduce a small claim or build a miniature experiment. Then read a critique or evaluation paper before treating the result as a capability guarantee.

For external projects, record the last-checked date in your own research log. Repositories change, licenses differ, and a popular project may not be maintained at the same level over time.
