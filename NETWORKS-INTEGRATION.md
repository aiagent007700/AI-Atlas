# Integration guide: autonomous networks, telecom and IT

This package adds a new public-facing documentation area under `docs/networks/`. It contains no release terminology in the tutorial pages.

## Add the sidebar category

Add this object inside the main `items` array in `sidebars.ts`:

```ts
{
  type: 'category',
  label: 'Autonomous networks, telecom and IT',
  items: [
    {
      type: 'autogenerated',
      dirName: 'networks',
    },
  ],
},
```

If you prefer to place it under an existing Atlas category, nest the same object there. Do not add individual document IDs; autogenerated navigation reduces link drift.

## Local validation

```bash
python scripts/preflight_networks.py
npm install
npm run build
```

The final Docusaurus build must be run from the full repository because this package is additive and does not contain your existing site's dependencies or configuration.
